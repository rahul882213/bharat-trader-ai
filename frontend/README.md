# Bharat Trader AI — Frontend Terminal

The React + TypeScript + Tailwind CSS + TradingView Lightweight Charts + Recharts terminal application is located at `/src` with `/index.html` and `/vite.config.ts` at the repository root for zero-configuration Vite + Express execution on port 3000.

## Key Libraries
- `lightweight-charts` (Interactive NSE/BSE candlesticks, volume, EMA 9/21/50, VWAP, Bollinger Bands, S/R levels)
- `recharts` (RSI, MACD, Equity Curve, and 10,000-Run Monte Carlo distribution charts)
- `lucide-react` (Affordance icons)
