# Feature Comparison: `day-trader-skill` vs `Bharat Trader AI`

This document maps the architecture and 11 trading skills of `jakeschincariol/day-trader-skill` (US Equities) to **Bharat Trader AI** (Indian Equities — NSE & BSE).

| Dimension | Reference (`jakeschincariol/day-trader-skill`) | Bharat Trader AI (Indian Market System) |
|---|---|---|
| **Exchanges & Universe** | NYSE / NASDAQ (~5,900 US tickers via Nasdaq Trader symbol list) | NSE & BSE (~2,000+ active equities via official NSE `EQUITY_L.csv` + NIFTY 50, Next 50, 100, 200, 500, Midcap 150, Smallcap 250, Bank Nifty, FinNifty, Sectoral Indices) |
| **Currency & Formatting** | USD (`$`) | INR (`₹`, Indian Lakhs/Crores numbering where appropriate) |
| **Market Hours & Calendar** | US Eastern Time (09:30–16:00 ET), US Federal holidays | IST (`Asia/Kolkata`): Pre-Open `09:00–09:15`, Regular `09:15–15:30`, Intraday MIS auto square-off `15:15`, Mon–Fri excluding NSE/BSE Exchange Holidays + Special Sessions (`config/market_calendar.json`) |
| **Module 1: Scanner** | `trader-scanner` (US breakout/oversold scan) | `modules/trader-scanner` — 14 setups (ORB, VWAP breakout, EMA crossover, RSI oversold reversal, MACD bullish crossover, BB squeeze, Volume breakout, Relative Strength vs NIFTY 50, 52W High, S/R breakout, Chart patterns, Gap Up/Down, Momentum, Unusual Volume) across `1m, 5m, 15m, 30m, 1h, 1d` |
| **Module 2: News Analyst** | `trader-news` (US news headlines) | `modules/trader-news` — Official NSE/BSE/SEBI/RBI feeds + Moneycontrol, Economic Times, Business Standard, CNBC-TV18 RSS with corporate event categorization (Results, Order Wins, Bulk/Block, Promoter/Insider, M&A, Fundraising, Policy) + Bullish/Bearish/Neutral impact synthesis |
| **Module 3: Entry Timing** | `trader-entry` (bar-by-bar entry timing) | `modules/trader-entry` — Strict closed-candle validation (never triggers breakout on forming candle), VWAP, EMA 9/21/50 alignment, volume ratio, S/R, R:R -> `WAIT / WATCH / ENTRY TRIGGERED / SETUP INVALIDATED` |
| **Module 4: Exit Planner** | `trader-exit` (SL/TP planning) | `modules/trader-exit` — ATR(14) + Swing structure + S/R -> Initial SL, Trailing SL rule, Target 1 / 2 / 3, R:R ratio, and 15:15 IST intraday time-exit |
| **Module 5: Backtester** | `trader-timemachine` (10,000 session replay) | `modules/trader-backtest` — Historical Intraday & Daily backtest with exact Indian statutory charges (STT, Exchange Txn, 18% GST, SEBI fee, Stamp Duty, Broker fee) + 10,000-run Monte Carlo resampling (labelled non-predictive) + look-ahead & survivorship bias controls |
| **Module 6: Risk Manager** | `trader-risk` (`PASS / BLOCK` check) | `modules/trader-risk` — Capital in INR, 1% max risk/trade, 3% max daily loss, max trades/day, max open positions, max sector & portfolio exposure, min 1:2 R:R enforcement |
| **Module 7: Position Sizer** | `trader-budget` (USD position sizing) | `modules/trader-budget` — Exact INR quantity sizing accounting for Indian brokerage/taxes, with separate Cash Equity and F&O (lot-size aware, disabled by default) modes |
| **Module 8: Broker Execution** | `trader-broker` (US broker / paper mode) | `modules/trader-broker` — Broker adapter architecture for **Zerodha Kite Connect**, **Upstox**, **Angel One SmartAPI**, **DhanHQ**, with **Paper Trading enabled by default** and mandatory 7-item explicit user confirmation before live order dispatch |
| **Module 9: Alerts** | `trader-alerts` (price alerts) | `modules/trader-alerts` — Entry, SL, Target, VWAP crossover, Volume spike, Breakout/Breakdown, Volatility alerts + optional Telegram Bot webhook |
| **Module 10: Fundamental Analyst** | `trader-earnings` (US SEC EDGAR earnings) | `modules/trader-analyst` — Indian Fundamental Analyst (Revenue/EBITDA/PAT/EPS growth, Operating Margin, ROE, ROCE, D/E, FCF, OCF, Working Capital, Promoter & Institutional holdings, P/E, Forward P/E, P/B, EV/EBITDA, PEG, P/S, DCF intrinsic estimate with disclosed assumptions, Peer Comparison) |
| **Module 11: Market Intelligence** | `trader-pelosi` (US Congress & SEC filings) | `modules/trader-intelligence` — NIFTY 50, BANK NIFTY, FINNIFTY, India VIX, Sector Rotation, Market Breadth, USD/INR, Crude Oil, Gold, RBI/SEBI updates, Bulk/Block/Promoter feed digest & Daily Market Briefing |
| **Shared State & CLI** | JSON pipeline files + Python CLI | `trader/*.json` pipeline handoff + `python3 main.py <command>` + FastAPI backend + Express/React/TradingView terminal UI + Gemini AI structured synthesis |
